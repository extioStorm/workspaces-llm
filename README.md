# workspaces-llm

Two [Acode](https://acode.app) plugins for packaging a project into one document for an AI/LLM.

| Plugin | What it is |
| --- | --- |
| [Bundle Workspace](bundle-workspace/) | Lightweight built-in bundler: pick files, get one XML/Markdown/plain document. |
| [ARepomixGUI](arepomixgui/) | A graphical wrapper for the [Repomix](https://github.com/yamadashy/repomix) CLI, run in Acode's terminal. |

Each folder holds the plugin source (`plugin.json`, `main.js`, `icon.png`, `readme.md`). To install, zip those four files and install the zip in Acode.

[docs/acode-plugin-notes.md](docs/acode-plugin-notes.md) has notes on Acode's plugin API gathered while building these.
